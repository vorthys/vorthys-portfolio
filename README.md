# Vorthys — demo portfolio

Пять демо-сайтов для портфолио фрилансера. Чистый HTML, CSS и немного JS —
без сборки, без зависимостей, работает на любом статическом хостинге.

| Демо | Что показывает | Язык |
|---|---|---|
| [`kavarna/`](kavarna/index.html) | Пражírna ZRNO: карточки обжарки с данными лота, шкала прожарки, бегущая строка | чешский |
| [`saas/`](saas/index.html) | Hodina: интерактивный герой — клик по блокам дня собирает счёт с пересчётом сумм и VAT | английский |
| [`studio/`](studio/index.html) | SVĚTLO: галерея-контактный лист с перфорацией плёнки, hover-проявка, лайтбокс | английский |
| [`fitness/`](fitness/index.html) | PULS: расписание недели, выбор слота попадает в форму записи с валидацией | чешский |
| [`smart-home/`](smart-home/index.html) | Дашборд умного дома на React + Tailwind (через CDN), орбитальная раскладка | русский/англ. |
| [`index.html`](index.html) | Витрина: карточки кейсов, услуги, процесс, цены | английский |

Все бренды вымышленные, данные демонстрационные. Фотографии — Unsplash.

## Локальный просмотр

```bash
python -m http.server 5180 --directory C:/Vorthys/portfolio
```

Затем открыть http://localhost:5180

## Что поправить под себя

- `index.html` — имя/бренд в шапке и футере, e-mail в секции контактов (`hello@example.com`), цены в блоке «Rates».
- В демо менять нечего, кроме случаев, когда нужен другой набор ниш: каждый файл самодостаточен.
- Шрифты грузятся с Google Fonts, изображения — с Unsplash CDN. Для офлайн-показа их нужно скачать локально.

## Проверено

Отсутствие горизонтального скролла на 375 px и 1280 px, загрузка шрифтов с
диакритикой, отсутствие битых изображений, работа интерактива (счёт в `saas`,
лайтбокс в `studio`, форма записи в `fitness`), `prefers-reduced-motion`.
